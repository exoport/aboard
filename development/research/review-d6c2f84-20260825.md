# aboard — final review at d6c2f84

## Verdict

Sound to build on. The build is clean (`go build`, `go vet`, `go test -race -count=3`, `make lint`, `xcompile-windows`, `docs-check`, 101/101 smoke), and the three properties the project sells — the four server-enforced tab guarantees, the self-describing manifest, and a CLI tree that mounts inside another binary with no ceremony — each held up under direct probing, not just reading. Two real defects sit under that, both in `server.go`, both narrow-window races, both a few lines to fix: the state write path has no mutual exclusion, so concurrent writes both return 200 and one is destroyed silently; and the SSE fanout sends on a channel the reader closes, which killed the process outright under a reproduced disconnect race. Everything else is medium or below, and much of the medium tier is documentation and test coverage rather than behaviour. The real state: a well-built system whose concurrency story was never written down, and whose suite — genuinely strong on layout, recipes, init and command parity — has an asymmetric blind spot. Nothing concurrent is tested, five of six `writeWarnings` detectors can be deleted with the suite green, and three browser-suite assertions cannot fail against the fixture they ship with. Fix the two highs, then close the coverage gaps plan-1 §13 already asked for.

## High

**Unserialised read-check-write in `postState`** — `pkg/aboard/server.go:568` — the read → CAS → reconcile → write span holds no lock (`s.mu` guards only fanout), so two overlapping POSTs both pass CAS and both write; 40/40 barrier-synchronised trials returned (200, 200) with one edit gone from disk, and the journal records the lost write as if it landed. — Hold a dedicated `sync.Mutex` from `os.ReadFile` (:568) through `writeAtomic` (:626); test N concurrent posts off one base for exactly one 200.

**`fanout` sends on a channel `events` closes** — `pkg/aboard/server.go:775` — channels are copied under `s.mu`, the lock released, then sent to; a client disconnecting in that window is closed first and the send panics. Reproduced fatally — `watch()` is a bare goroutine with no recover, the process died, `aboard status` reported a stale record. `notifyWatchers` (`journal.go:282`) is the same shape. — Delete from the map without closing (nothing else reads it), or hold `s.mu` across the non-blocking sends; add `recover()` to `watch`/`watchUI`.

## Medium

**`apply` disables compare-and-set with no `updatedAt`** — `client.go:84` — `__base` is set only when present and the server skips the check when empty, so a write built from the documented minimal shape clobbers everything since the last read, exit 0, no stderr. — Warn, or refuse without `--force`.

**The CAS token is a millisecond timestamp** — `server.go:611` — 4 collisions in 60 sequential writes, after which a provably stale `__base` passes; reproduced through the real `apply` client, human edit lost. — Compare a monotonic revision or the sha256 `stateSignature` already computes.

**An agent write erases a `pendingRemoval`** — `tabs.go:150` — `touched`, `seen` and acks carry forward, `pendingRemoval` is taken verbatim, so a routine read-modify-write cancels another agent's request and the human's banner vanishes. — Mirror the `touched` rule for non-human writers.

**No origin check on `POST /aboard.json`; `__by: "human"` comes from the body** — `server.go:560` — any page in the developer's browser can wipe or plant tabs cross-origin (reproduced in headless Chromium from another local origin), and a pure deletion writes no journal entry, so nothing survives to restore from. — Refuse foreign `Sec-Fetch-Site`/`Origin` in `route`, before parsing.

**No `Host`-header validation** — `server.go:418` — any hostname resolving to loopback is answered, so a DNS rebind makes an attacker page same-origin and able to *read* `/aboard.json`, `/journal` and `/health` (which discloses the absolute project path and pid). — Allow-list `localhost`/`127.0.0.1`/`::1` at the top of `route`.

**An explicit `--port`/`PORT` bypasses duplicate detection** — `server.go:276` — `listen()` returns early when `want != 0`, so a second server runs on the same state file and rewrites `instance.json`; killing it points every client command at a dead port while a healthy board serves. — Hoist the `probeOccupant` check above the branch.

**A symlinked project path derives a second port** — `layout.go:212` — `FindRoot` never calls `EvalSymlinks`: one project, two roots, two servers, and the second's exit deletes the shared `instance.json`. Board content survives; discovery does not. — `EvalSymlinks` the found directory.

**`--name`/`ABOARD_NAME` is interpolated into filenames unvalidated** — `layout.go:104` — `..` escapes `.aboard/`, `.aboard/run/` and the project root; `--name '../../../../evil'` wrote both files outside the tree, reported as success, uncovered by `.gitignore`. — Validate `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$` in `boardName()`, as `logTabRe` already does.

**`journal`'s disk fallback misses the stale-instance case** — `journal.go:323` — it fires only when the instance *file* is unreadable, so after a crash the documented third resume command exits 1 with a dial error while `journal.jsonl` sits readable beside it. — Fall back on transport failure too.

**`init` mutates the project, then exits 2** — `cli/init.go:53` — `--output-format` is validated inside `renderOutput`, after the board and the `.gitignore` line are written, though the declared table defines 2 as "before anything was contacted"; the corrected retry then exits 1 "already exists". — Validate before the side effect.

**Argument-count errors exit 1, not the declared 2** — `cli/root.go:62` — cobra's `Args` validators return untyped errors, so `aboard export` with no argument is indistinguishable from `aboard export nosuchtab`, and the manifest advertises 2 for exactly this. — Wrap the validators in `usageErr`.

**`--output-format yaml` is a different, lossier document** — `cli/format.go:26` — no output struct carries yaml tags, so keys lowercase (`capsHash`→`capshash`) and `omitempty` is ignored; worse, `recipes list` in yaml drops `scope`, `path`, `shadowedBy` and the parse error — the three things the command exists to report. — Paired yaml tags; a separate output struct for `Recipe`.

**The parity test never descends into subcommands** — `cli/parity_test.go:42` — `recipes list --output-format` and `recipes show --template` are declared nowhere and asserted by nothing; adding a flag to `recipes show` leaves the suite green and `capsHash` unchanged. — A `Subcommands` field, plus a recursive walk.

**Id reconciliation has no test** — `ids.go:56` — a plan-1 §13 must-cover item: `reconcileNextID` can be gutted to "return the incoming `nextId`" with everything still green, while a handoff schedules a refactor of this exact function expecting a safety net. — Table-test the floor, the never-go-backwards rule, and ids present only in the current document.

**`writeWarnings` rests on one count assertion** — `init_test.go:330` — five of six detectors (unknown prop, undeclared state key, bad block field, dead `{bind}`, unknown tone/colour) can each be disabled with `go test ./...` green; they live only in the local shell suite. — One minimal document per class, plus the two negative cases.

**`make smoke` skips a third of its checks and exits 0** — `Makefile:163` — no `build` prerequisite, five sections degrade to a printed skip, reachable via `make clean`, `make install` and `make dev`; real spec drift passes with no binary and fails with one. — `smoke: build`, and exit non-zero on any skip.

**Nine render-count probes are logged, never compared** — `web/test/smoke.html:182` — the consumer fails only on `THREW|MISSING EXPORT|ERROR|REJECTION`, so `mermaid svg rendered: 0` prints `ok`; reproduced with a deliberately broken renderer. — Emit `got/want`, or a threshold table.

**The read-only kanban assertion is vacuous against its own fixture** — `test/smoke.sh:681` — `bb71` ships `nodes: []`, so `cards === chips === 0` and the no-drag/no-edit negatives are trivially true; a renderer patched to emit drag handles and editable titles still passes. — Give `bb71` cards; require `cards > 0`.

**An SSE reload discards an edit inside the 250 ms debounce** — `web/aboard.html:1261` — `load()` replaces `doc` and resets `baseline` unconditionally, so a foreign write mid-debounce swaps the state behind the textarea; the pending save posts the server's own copy, gets 200 and flashes "Saved". Reproduced in Chromium; the same edit survives with `?nosse=1`. — Route the SSE path through `mergeOntoFresh()` and re-arm `saveTimer`.

**`baseline` is never advanced after a 409 merge** — `web/aboard.html:332` — a second 409 reclassifies the adopted agent copy as the human's edit and overwrites the stash with it, so "Restore mine" hands back the agent's text under "Your version was kept." — `baseline = snapshot(merged)` where `doc = merged`; never overwrite an existing stash entry.

**Three docs claim a `go install` build reports version `dev`** — `README.md:42`, `docs/how-to/install.md:17`, `docs/how-to/verify.md:80` — it reports the module version or a pseudo-version (verified via a real file-proxy `go install`), and `verify.md` uses the false claim as its argument for taking a signed archive; once `v0.1.0` is tagged only the signature distinguishes the two.

## Low (15 confirmed, 18 unverified)

Confirmed: `mergeSeen` skips its writer filter when a tab has no `seen` map, and tab *creation* bypasses it entirely (`tabs.go:337`). `/tab/<id>/html` carries no CSP `sandbox` directive, so a standalone fetch runs same-origin (`htmltab.go:31`) — note the proposed `sandbox allow-scripts` blocks popups but *not* self-navigation, so it is hardening, not an egress fix. `writeAtomic` silently drops the state file to 0600 against a documented 0644 policy (`server.go:650`). `init --gitignore` failing at the last step reports total failure having already created the board (`init.go:186`). One unreadable or dangling `.md` aborts all recipe discovery including the built-ins (`recipes.go:270`). Two `log.Printf` calls bypass `Options.Logger` (`tabs.go:209`, `server.go:876`). Every user-facing message hardcodes `aboard`, so a hosted tree names a command the user lacks (`client.go:217`); under embedding, `version`/`/health`/`instance.json` report the *host's* commit as aboard's (`version.go:110`) — both latent until ape mounts the tree. Base-path injection and the wait-predicate vocabulary have no Go test (`server.go:817`, `wait.go:196`), though both are correct today. The recipe index is the one `make caps` artifact with no drift gate (`Makefile:36`). And four doc claims are false: `.gitattributes`' `-text` rationale (load-bearing, but not for the stated reason), "no `filepath.Join` outside layout.go" (four violations, nothing checks it), http-api.md's "anything unmatched is 404" (it is 403, and `POST /` returns the shell), and SKILL.md's `make caps` remedy in a project that only copied the skill.

Unverified, worth one pass: journal rotation makes the kept generation unreachable — `tail` never reads `journal.jsonl.1`, so history goes invisible after 16 MiB; the largest of the group and it looks real. Then `--dev` follows symlinks out of the web tree; `POST /log?tab=` creates unbounded sidecar files for tabs that do not exist; a `ui` link with a root-absolute href ignores `--base-path`; markup's TYPES `init` disagrees with its spec, so the generated reference states a false starting shape; `BUILD_DATE` is the commit date, wrong on exactly the dirty build it exists for; `--help` sorts alphabetically despite a comment claiming declaration order; a recipe in a subdirectory is silently dropped while the how-to promises otherwise; `TestManifestAppIsHostIndependent` compares a constant to itself; and an unescaped backtick at `smoke.sh:750` runs the `wait` builtin inside a skip message.

## What is sound

Exercised, not merely read. **The four guarantees**: a dropped tab returns as a `pendingRemoval` and `reconcileNextID` scans *both* documents so a restored tab's ids still raise the counter; an omitted `touched` carries forward verbatim over HTTP; `carryAcks`/`restoreAcks` walk shape-tolerantly; a missing `__by` yields `actorUnknown` with agent powers only, and `apply` refuses `--by human`. **Containment where it counts**: loopback-only bind confirmed with `ss`; the html-tab CSP byte-identical for a tab and a stack block, `connect-src 'none'` intact, `sandbox="allow-scripts"` without `allow-same-origin`; uploads sniffed from magic bytes with the server choosing the filename and SVG excluded; every body-reading route capped; base-path stripping resistant to `..`, `%2f` and `--path-as-is`; static serving allow-listed; mermaid at `securityLevel: 'strict'` and no view putting untrusted text through `innerHTML`. **Embeddability**: a mock ape host mounted `cli.NewRootCmd` and ran `--help`, `status`, `version` and `serve` with zero ceremony; `Options.Stdin/Stdout/Stderr` honoured by every client command; `signal.NotifyContext` confined to `Execute`, so mounting steals no signals. **Layout**: `--cwd p1`, `--cwd p1/` and a subdirectory run all resolve to one root and one port; a *file* named `.aboard` is not a root; Init's five nesting rules behave as documented; port derivation pinned to exact vectors rather than a range; `init --example` recomputes `nextId` instead of copying it. **Recipes**: four-tier precedence with the winner naming every file it shadows, frontmatter tolerances (BOM, CRLF, padded delimiter) with matching negatives, invalid files reported with the reason rather than skipped, template extraction past a decoy ```json fence, index determinism — and the built-ins are live, four applied against a running board. **The manifest at the top level**: `capsHash` drift is CI-gated through the stamped controls module (verified by deliberately drifting a spec), `gen-docs --out -` reproduces `docs/reference/cli.md` byte-identically, and `make caps` is idempotent with a load-bearing double build. **The browser**: every URL goes through `api()`, `--base-path /brd` verified live end to end including uploads and the html-tab route, the `aboard.*` bridge rename complete, TYPES/MODULES/specs 15/15/15 with all 15 mounting headlessly at zero window errors and 131 declared controls. **Release plumbing**: `.bingo` pins match ape's, goreleaser-action pinned to the bingo pin (stricter than ape), the cosign identity regexp anchored and escaped, `GOOS=windows` vet/build/test-compile clean, NOTICE's mermaid version and sha256 both reproducing.

## What this review could not verify locally

The DNS-rebinding chain itself needs attacker DNS and a browser — only Host-acceptance and the `/health` disclosure were demonstrated, and the derived-port range (41000–48999) makes it harder than a fixed-port dev server. The embedded-host version and invocation-string defects are latent: ape has no dependency on this module yet, so nobody can hit them today. Cross-uid consequences of the 0600 mode change were reasoned about, not reproduced. Windows is covered only by cross-compilation and test compilation, never by running the suite there. Nothing was tested behind a real reverse proxy, so `--base-path` is proven against curl and Chromium but not nginx or the VS Code webview in anger. And both high findings needed deliberate pressure to reproduce — barrier synchronisation for the write race, 350 SSE clients timed against the watcher's 200 ms poll for the panic — so neither shows up in casual single-session use, which is exactly why they survived this long.
